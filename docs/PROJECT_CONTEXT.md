# 项目上下文

这份文档供本 iOS 项目继续开发时复用，记录产品边界和已核对来源，不复制其他聊天的完整历史、私有运行配置或生产授权。

## 用户目标

把博客看板娘「泠月喵」搬到 iPhone 灵动岛。首版支持查看服务器状态、博客近期内容、简单事务处理和闲聊；不迁移完整博客 iOS 应用。

用户开发环境为 Windows，设备为 iPhone 15 Pro，没有 Mac、没有付费 Apple Developer Program 会员。用户明确同意创建公开 GitHub 仓库 `saudade-agent-ios`，使用免费的标准 macOS GitHub Actions 编译，再评估 Windows 免费签名侧载。

## 复用的项目事实

- Python Agent 是 FastAPI + LangChain `create_agent` + LangGraph checkpoint；DBOS 承担可选后台计划。
- Rust 宿主负责博客登录、身份断言、权限、会话与历史。iOS 调用宿主公开 API，不直连内部 Agent，不自己签身份或委托。
- 现有 SSE v2 区分正文、进度、确认卡、客户端命令、完成和错误。客户端必须发送版本头；收到 `done` 才能将回复标为完整。
- 写入依靠服务端签名确认卡、对象版本和执行账。正文、人设或摘要不能授权。断连不等于未执行，未知结果不能盲目重放。
- 聊天中使用现有 Agent 的人设和记忆，不在手机重新维护一套模型系统提示与长期记忆。不同账号、会话与角色的隔离沿用宿主边界。

## 关键设计

- SwiftUI 轻量应用承载键盘聊天、诊断详情和确认卡；WidgetKit + ActivityKit 承载灵动岛。
- iOS 17 起用 App Intent 执行“刷新状态”；点击聊天入口深链回原生应用。
- 无 App Group、无远程推送、无 Live2D SDK。刷新 Intent 在主应用进程执行，渲染扩展不读取登录凭据。
- 普通 Live Activity 最长 8 小时，旧数据五分钟后显示待更新。不用后台轮询伪装永久宠物。
- 原生仅支持完整文本审阅；图片、封面、批量卡保留到博客处理。原生不会执行网页或编辑器命令，也不回报虚构的浏览器状态。
- 默认演示模式明确使用模拟数据。真实诊断错误保持未知，不显示虚构健康状态。

## 后续接入条件

1. 对应提交的 CI 必须通过，尤其应用与扩展都需构建。
2. 通过 Windows 签名侧载到 iPhone，保留 Widget 扩展，再实测 Live Activity Intent 的刷新与深链。
3. 使用真实博客账号登录后验证服务部署兼容性；诊断需管理员身份。
4. 生产写入测试、生产部署和其他对话的授权不因这份文档自动继承。首版离线测试无需模型或生产数据库。
5. APNs、后台通知、完整会话列表与复杂确认 UI 是后续扩展，不能把当前原型描述为已支持。

- 人工事务是评论、留言审核与额度申请等业务队列，暂停 Agent 执行单列；不把两者混为待办数量。未知汇总时仍展示已读到的待办下限。
- 原生 Markdown、24 张离线贴纸、登录用户昵称头像、博客风格日夜登录、新 AppIcon 与透明头部已接入；美术来源和提示词见 `Artwork/README.md`，不再使用首版原始大头像。
- 支持自己的 HTTPS 域名和账号，不绑定作者部署。登录后显示身份卡，主动切换账号才打开登录表单。
- 结束陪伴入口位于应用、锁屏和灵动岛展开区；移除实时活动并停止接收，不使用 exit(0) 强杀 App，不保证远端操作被撤销。
- 后台无轮询，流式渲染和内存/图像/日志有上限。真实后台挂起、电量与新包交互仍需 iPhone 验证，不能用 CI 编译替代真机验收。
